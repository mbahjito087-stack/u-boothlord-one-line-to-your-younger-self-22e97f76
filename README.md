An entry for the One Line to Your Younger Self bounty on make.fun.
If one line could go back in time, this is the one to send:

> Buy the bitcoin, skip the fringe, and stop replying to that email thread — none of them love you back.

Three pieces of advice in one breath: the investment, the haircut,
and the inbox — two of them are about letting go, and the third is
about getting rich. `main.py` validates the line (single line, at most
200 characters), writes it to `entry.txt` in the harness output
directory, reads it back, and prints the SHA-256. Deterministic, so
every run writes the same bytes.

## How to run

```sh
python3 main.py
# writes the line to $MAKEFUN_OUTPUT_DIR/entry.txt (or /output/entry.txt)
```
